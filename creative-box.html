Лінійка 2

🎨 Творчий бокс

Повний набір для створення власних NFC-продуктів. Усе, що потрібно, — вже всередині: заготовки, чіпи та покрокова інструкція. Створи свій AuraTag своїми руками.

  • Акрилові заготовки брелоків: круг, прямокутник, квадрат
  • Заготовки значків трьох розмірів
  • NFC-чіпи-наклейки — просто приклей і запрограмують
  • Фірмова інструкція з покроковою відеонавчанням
  • Голографічне пакування — готово і для подарунка

Ціна: від 100 ₴

Ціна залежить від комплектації — уточнюй при замовленні.

Що можна створити

Ідей для використання — безліч

  1. Брелок із піснею — для себе або в подарунок другу
  2. Значок для чаєвих — ідеально для бариста чи офіціанта
  3. Значок для донатів — блогерам, вуличним музикантам, волонтерам
  4. Власний мерч — логотип або дизайн, який придумаєш ти
